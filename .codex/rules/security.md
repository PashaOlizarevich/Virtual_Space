# Безопасность

- Считай формы, URL, JSON, headers, localStorage и данные внешних сервисов недоверенными.
- Валидируй вход на сервере и применяй принцип минимальных привилегий.
- Проверяй Auth.js session и роль `ADMIN` в каждом защищённом server entry point.
- Секреты остаются server-only; не используй `NEXT_PUBLIC_` для чувствительных значений.
- Не читай и не выводи `.env`; в `.env.example` допускаются только безопасные заглушки.
- Не логируй токены, cookies, пароли, полный заказ и персональные данные.
- Защищай загрузки ограничениями типа/размера и серверной подписью Cloudinary.
- Для endpoint проверь IDOR, mass assignment, инъекции, раскрытие ошибок и rate-abuse риск.
- Для чувствительных изменений и перед production-релизом выполняй read-only `security-review`.
- Выбирай CSRF, CSP, cookie и rate-limit меры по модели угроз; не добавляй их механически.
- Не выполняй автоматическое исправление dependency audit без review и разрешения.
