# Backend

- Server Action используй для мутаций собственного UI; Route Handler — для JSON API, callbacks и внешних клиентов.
- Transport валидирует вход, проверяет сессию/роль, вызывает сервис и формирует безопасный DTO.
- Бизнес-правила и транзакционные границы размещай в сервисах доменного модуля.
- Все входные данные, query-параметры и внешние payload валидируй через Zod.
- Каждый защищённый handler/action самостоятельно проверяет доступ; скрытый UI не является защитой.
- Не возвращай Prisma-модели, stack traces, секреты или внутренние детали.
- Перед заказом повторно получай товары из БД и пересчитывай цены и доступность на сервере.
- Cloudinary и Telegram изолируй адаптерами; Telegram вызывай best-effort после фиксации заказа.
