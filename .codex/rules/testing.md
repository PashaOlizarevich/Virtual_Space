# Тестирование и проверки

- Jest используй для unit/integration-тестов, Playwright — для критических пользовательских E2E.
- Тестируй наблюдаемое поведение и доменные инварианты, а не детали реализации.
- Для дефекта добавляй regression-тест, если он стабилен и соразмерен исправлению.
- Минимальные проверки: `npm run lint`, `npm run typecheck`, затронутые тесты.
- Перед передачей по возможности запускай `npm test -- --runInBand` и `npm run build`.
- Для пользовательских потоков запускай `npm run test:e2e`; для Prisma — проверки database rules.
- Не обновляй snapshots и ожидания только ради зелёного результата.
- В отчёте укажи команды, результат и причины пропущенных проверок.
