# База данных

- PostgreSQL — источник истины; Prisma — основной способ доступа к данным.
- Импортируй Prisma только в server-only коде и используй единый PrismaClient singleton.
- Схема и миграции должны отражать доменные инварианты, связи, индексы и ограничения.
- Денежные значения не храни в JavaScript `float`; используй точное представление.
- Связанные записи заказа создавай атомарно в транзакции.
- Перед изменением схемы оцени совместимость, существующие данные, backfill и путь отката.
- Не применяй destructive migration, reset, seed или изменение production-БД без разрешения.
- После изменения запускай `npm run prisma:validate` и `npm run prisma:generate`; миграцию создавай только в границах задачи.
