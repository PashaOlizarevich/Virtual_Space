# Общие правила проекта

- Источники требований: `docs/architecture.md`, `docs/TermsOfReference.md`, `docs/DESIGN.md`, фактический код и конфигурация. При конфликте сообщи о нём до изменения решения.
- Проект находится на стадии каркаса: проверяй наличие реализации, не ориентируйся только на ТЗ.
- Используй Node.js 24+, npm 11+ и существующий `package-lock.json`.
- Соблюдай строгий TypeScript, alias `@/*` и настройки `.prettierrc.json`.
- Не изменяй `next-env.d.ts` вручную и не создавай зависимости без разрешения.
- Не реализуй функции следующих этапов вместе с MVP без прямого запроса.
