# Git

- Если Git доступен, перед работой выполни `git status --short` и `git branch --show-current`.
- Считай существующие изменения пользовательскими, пока не доказано обратное.
- Не форматируй и не переписывай несвязанные файлы.
- Не используй `git reset --hard`, `git checkout --`, force push и другие destructive-команды.
- Commit, push, merge, rebase, ветки и PR выполняй только по прямому запросу.
- Перед завершением просмотри diff, проверь область изменений, секреты и временные артефакты.
- Предлагай conventional commit-сообщение, но не создавай коммит автоматически.
