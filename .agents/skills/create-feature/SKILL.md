# Создание функционала

## Назначение

Реализовать минимальный вертикальный срез функции без расширения области задачи.

## Порядок действий

1. Прочитать связанные разделы ТЗ, архитектуры и дизайн-системы.
2. Найти связанные модули, маршруты, типы, тесты и публичные контракты; определить этап продукта.
3. Описать поток данных и минимальный набор изменений от UI до хранения или интеграции.
4. Реализовать schemas/DTO, server service/query, transport, затем UI.
5. Добавить тесты ключевого поведения и ошибок.
6. Для чувствительной функции выполнить `$security-review` и устранить подтверждённые риски.
7. Запустить lint, typecheck, затронутые тесты и build; для потока — E2E.

## Ограничения

- Не добавлять функции следующих этапов, зависимости и новые слои без согласования.
- Не помещать бизнес-логику в `app`, UI или transport.
- Не доверять клиентским ценам, правам и localStorage.

## Критерии завершения

- Сценарий работает от входа до результата, ошибки обработаны, доступ проверен.
- Архитектурные границы сохранены, проверки пройдены либо ограничения зафиксированы.
